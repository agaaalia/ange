# Angela's Quest ♥

A tap-to-advance 8-bit wedding card for Angela & Nielsen.

**Snapshots:** Title → 07:00 AM glow-up (a mini-game: tap the towel, the Vaseline, the hairdryer and the dress) → 06:30 PM matcha (tap to whisk, with the kids and Churros the bunny around) → 09:00 AM kopi run at the office → doki doki by the bay → The Big Day at the Peranakan shophouses with the whole family → a letter pops up.

Scene changes are cute wipes: Churros hopping past, a matcha whisk with a face, a flying rainbow bear, a big heart.

Plain HTML/CSS/JS. No build step and no image files: every sprite is drawn in code on a 240×160 canvas. The music is a small chiptune synth (an original adventure tune, a waltz, and a fanfare into Wagner's *Bridal Chorus*, which is public domain).

## Write the letter
Open `index.html` and edit the block between the `✏️ WRITE YOUR LETTER BELOW` comments. Each `<p>…</p>` is one paragraph.

## Publish on GitHub Pages
Settings → Pages → *Deploy from a branch* → choose this branch and `/ (root)` → Save.
The card will be live at `https://<username>.github.io/ange/` within a minute or two.

## Preview locally
Open `index.html` in a browser, or run `python3 -m http.server` and visit http://localhost:8000.
